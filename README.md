# Gaze Lab v0.8.1

시각 추적 연구의 검증용 로컬 웹입니다. MediaPipe 기반으로 시선 방향, 머리 방향, 화면 안/밖 주시 횟수와 시간을 기록합니다. 반응시간·지연시간의 수동 사건 기록도 지원합니다. 인지검사 문항과 채점은 포함하지 않습니다.

## 실행

Node.js 20 이상이 필요합니다. 별도 패키지 설치나 빌드 없이 실행합니다.

    npm start

브라우저에서 http://localhost:4173/ 을 엽니다. Windows에서는 Start-Test.ps1로 서버 실행과 브라우저 열기를 함께 할 수 있습니다. 서버는 127.0.0.1에만 연결됩니다. 웹캠에는 카메라 권한이 필요합니다.

## 측정 순서

1. 대상자를 등록하거나 선택하고 새 측정을 엽니다.
2. 기기·거리·조명·카메라 위치를 처음 한 번 입력합니다.
3. **카메라 연결 · 자동 보정**을 누르고 9개 점을 순서대로 바라봅니다. 점마다 수집 버튼을 누르지 않습니다.
4. 보정 후 **화면 안 주시 · 10회** 또는 **화면 밖 주시 · 10회**를 선택합니다. 기본 회차 길이는 4초이며 자동 진행합니다. 화면 밖에는 실제 표적을 설치하고 머리를 고정한 채 눈만 움직입니다.
5. 종료 후 자동 저장되며 **10회 중 인식 횟수 / 시작·끝 / 총시간**을 먼저 표시합니다. 회차별 방향과 원자료는 펼쳐 보거나 CSV로 내려받습니다.

보정·대기는 측정 시간에 포함하지 않습니다. 각 회차에서 연속 0.5초 이상 해당 상태가 추정되면 1회 인식합니다. 중단·미제시 회차는 계획 분모에 남습니다. 얼굴 소실·눈 감음·관측 공백은 측정 실패로 구분하며 화면 밖 주시로 세지 않습니다. 총시간은 해당 상태 구간의 합계입니다.

**내 시선 위치 표시**는 보정 후 추정 좌표를 청록색 원으로 표시합니다. 데모는 합성자료입니다. 보정 수집 수와 프로그램 인식 수는 검증된 정답 수가 아닙니다. 실제 시선 정확도는 독립 표적과 영상 관찰로 검증해야 합니다.

## 데이터 보관

대상자 정보와 측정은 현재 브라우저에 보관하며 서버나 외부 서비스로 업로드하지 않습니다. 반복 열 이름을 줄여 관측값과 시각을 손실 없이 저장합니다. 전체 JSON 백업과 CSV 내보내기를 지원합니다. 선택 녹화 영상은 메모리에만 남으므로 페이지를 닫기 전에 별도로 내려받으세요.

측정자료, 대상자 명단, 영상, 연구계획서, 개인 백업 파일은 Git에 올리지 마세요. 저장소에는 소스와 합성자료 기반 테스트만 포함합니다. .gitignore가 일반적인 출력 파일을 제외하며 새 파일도 업로드 전에 확인하세요.

## 검증

    npm test

보정, 인식 분모·분자, 주시 시간, 관측 소실, 방향, 내보내기, 대상자 기록, 백업과 저장 복구를 검사합니다. 자동시험은 실제 시선 정확도를 입증하지 않습니다.

## 파일 구성

- dist/: 브라우저 소스와 추적 모델. 별도 빌드가 없으므로 dist도 Git에 포함합니다.
- dist/vendor/: MediaPipe 코드·WASM·모델 및 제3자 라이선스·출처.
- server.mjs: 로컬 서버.
- *-tests.mjs: 합성자료 기반 자동시험.
- 검증지표명세.md / 산출용 데이터 안내.md: 측정 기준과 CSV 설명.

## Git에 올리기

이 폴더를 저장소 루트로 사용합니다. 원격 저장소를 만든 후 실제 주소를 연결하세요.

    git status
    git commit -m "Add gaze tracking validation web app"
    git remote add origin <YOUR_REPOSITORY_URL>
    git push -u origin main

이미 origin이 있으면 remote add를 다시 실행할 필요가 없습니다. ZIP을 사용하면 압축을 푼 폴더에서 먼저 다음을 실행합니다.

    git init -b main
    git add .

제3자 코드의 dist/vendor/LICENSE와 NOTICE.txt를 보존하세요. 프로젝트 자체의 공개 라이선스는 아직 지정하지 않았습니다.

## GitHub Pages에서 열기

저장소 Settings → Pages에서 Source는 **Deploy from a branch**, Branch는 **main**, 폴더는 **/(root)**로 선택합니다.

최상위 index.html은 ./dist/의 앱으로 연결합니다. .nojekyll은 모델·WASM을 포함한 정적 파일을 그대로 게시하게 합니다. 이 두 파일을 삭제하지 마세요. GitHub Pages에서는 Node 서버를 실행하지 않고 브라우저 앱을 직접 제공합니다.

GitHub Desktop에서 변경사항을 Commit to main → Push origin으로 올립니다. GitHub 저장소의 Actions에서 pages build and deployment가 성공하면 Pages 주소로 접속합니다. 업데이트가 안 보이면 새로고침하세요.

localhost의 대상자·측정 기록은 배포 사이트로 자동 복사되지 않습니다. 필요하면 로컬 사이트에서 전체 백업을 내려받아 배포 사이트에서 직접 복원하세요. 개인 백업을 Git에 추가하지 마세요.

## v0.8.1 버튼 동작 수정

보정 시 자동 전체화면 전환을 사용하지 않습니다. 창 크기가 바뀌면 카메라 연결을 유지한 채 재보정을 안내합니다. 버튼 아래에 현재 준비 상태와 잠금 이유를 표시합니다. 10회 테스트 종료 후에는 결과를 저장하고 보정과 카메라를 유지합니다. 결과 화면의 다음 주시 테스트 버튼으로 화면 안/밖 테스트를 이어서 선택할 수 있습니다. 각 테스트는 새 세션 ID와 0초 시간축을 사용합니다. 느린 카메라는 최소 유효 프레임 수를 유지하면서 최대 4초까지 보정 관측을 모읍니다.

GitHub Desktop에서 변경사항을 Commit to main → Push origin으로 올리고 Pages 배포 성공 후 Ctrl+Shift+R로 새로고침하세요. 화면 버전이 v0.8.1인지 확인합니다.
